UUID Generator

Generate UUIDs in bulk. Version 4 uses the browser's cryptographic random number generator; version 7 is time-ordered, which keeps database indexes happy because generated values sort chronologically. Format them however your target system expects.

How to use this tool

  1. Choose the version: v4 (random) is the usual choice; v7 (time-ordered) sorts chronologically and indexes better in databases.
  2. Set how many you need — up to 1000 at a time.
  3. Adjust the formatting options if you need uppercase, braces, or the hyphens removed.
  4. Press Generate, then copy them all or download as a text file.
