Regex Tester

Test a JavaScript regular expression against sample text and see every match highlighted in context, with capture groups, named groups and match positions listed underneath. Includes a replacement preview so you can check a substitution before running it for real.

How to use this tool

  1. Type your pattern (without the surrounding slashes) and tick the flags you need.
  2. Paste the text to test against — matches highlight live as you type.
  3. Every match is listed with its position and any capture groups, including named groups.
  4. Enter a replacement string to preview a substitution. Use $1, $2 for capture groups.
