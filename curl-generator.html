cURL Command Builder

Build a correctly quoted cURL command from a method, URL, headers and body — then copy it straight into a terminal or a ticket. Or paste an existing cURL command (the kind you copy out of browser dev tools) and see it broken down into its parts.

How to use this tool

  1. In Build, choose the method, enter the URL, add one header per line as Name: Value, and paste a body if you need one.
  2. The command is generated as you type, with correct shell quoting for values containing spaces or quotes.
  3. In Parse, paste any cURL command to see the method, URL, headers and body laid out in a table.
  4. Parsing understands the flags dev tools emit: -X -H -d --data-raw -u -k -b -A and more.
