XPath Tester

Evaluate an XPath 1.0 expression against an XML document and see every matched node, its type and its serialised value. Handy when writing DataWeave that reads XML, debugging a SOAP payload, or checking a selector before putting it in production code.

How to use this tool

  1. Paste a well-formed XML document into the left box.
  2. Type an XPath expression such as //order/customer or count(//item).
  3. Press Evaluate — matched nodes are listed with their type and value.
  4. Expressions returning a number, string or boolean are supported too, not just node sets.
XML document
Browsers implement XPath 1.0. Expressions using XPath 2.0+ functions will not evaluate here. Documents using namespaces need namespace-aware expressions, for example //*[local-name()='Envelope'].
