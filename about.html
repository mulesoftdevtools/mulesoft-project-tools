About MuleSoft Project Tools

What this site is, how it works, and why it is free.

MuleSoft Project Tools is a free collection of 27 browser-based utilities for people who build and test integrations — MuleSoft developers in particular, but most of the tools are useful to any developer or QA engineer working with APIs and data formats.

Everything runs in your browser

There is no backend. Every tool on this site is plain HTML, CSS and JavaScript served as static files. When you paste a payload, an API specification or a token into one of these tools, it is processed by JavaScript running on your own machine and never sent anywhere. You can verify this yourself: open your browser's network tab and watch — after the page loads, nothing leaves.

A practical side effect is that the tools keep working offline. Once a page has loaded you can disconnect entirely and it will still function.

No accounts, no API keys, no limits

You do not need to sign up, log in, or provide an API key for anything here. There are no usage quotas and no paywalled features.

Why it exists

Integration work involves a lot of small, repetitive chores: reformatting a payload to read it, converting a spec between JSON and YAML, working out whether a cron expression really fires when you think it does, decoding a token to see why a call is being rejected. Each one takes a minute, and collectively they take a lot of minutes. This site collects the ones we reached for most often into a single place with a consistent interface.

About accuracy

These tools are built carefully and tested, but they are helpers, not authorities. In particular the RAML to OpenAPI converter is explicitly a best-effort translation: RAML features such as traits, resource types and multi-file includes have no clean one-to-one OpenAPI equivalent, so the converter reports what it could not translate instead of silently dropping it. Always review generated output before committing it to a project.

Open to feedback

If a tool gives you a result that looks wrong, or you keep wishing for one that is not here, the contact page explains how to get in touch. Bug reports that include the input you used are especially welcome.
