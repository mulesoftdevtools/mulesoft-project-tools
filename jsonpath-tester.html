JSONPath Tester

Run a JSONPath expression against a JSON document and see every match with its exact path. Supports the full everyday syntax — child and recursive descent (..), wildcards, indexes, negative indexes, slices, unions and filters such as [?(@.price < 10 && @.isbn)] or =~ /regex/i. For most expressions the tool also shows the equivalent DataWeave selector, which is handy when porting a mapping into Mule.

How to use this tool

  1. Paste a JSON document on the left, or press Load example.
  2. Type a JSONPath expression into the Expression box — results update as you type.
  3. Click one of the example expressions to see common patterns in action.
  4. Copy or download the matched values as a JSON array.
