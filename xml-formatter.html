XML Formatter & Validator

Format XML with clean indentation so you can actually read it, or minify it for transport. Every run also checks that the document is well-formed and reports the parser's error message if it is not — useful for SOAP payloads, Mule configuration files and RAML/XSD fragments.

How to use this tool

  1. Paste your XML — it is formatted and checked automatically as you type.
  2. Choose an indentation width, or pick Minify to strip formatting whitespace.
  3. If the document is not well-formed you get the parser's message describing what went wrong.
  4. Copy or download the tidied result.
