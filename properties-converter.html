Properties ⇄ YAML Converter

Convert between Java/Mule .properties files and YAML. Mule 4 supports both formats for configuration, and dotted property keys map naturally onto nested YAML — this tool does that mapping in both directions, preserving comments where it can.

How to use this tool

  1. Paste a .properties file (or a YAML config) into the input box.
  2. Choose the direction — or leave it on Auto-detect.
  3. Dotted keys such as http.listener.port=8081 become nested YAML, and nested YAML flattens back into dotted keys.
  4. Copy or download the converted configuration into your Mule project's src/main/resources.
