JSON to DataWeave Generator

Paste an example of the payload your flow receives and get a complete DataWeave 2.0 script that maps every field — nested objects become nested objects, arrays become map calls with sensible lambda names, and awkward keys such as order-date are quoted correctly. Rename keys to camelCase or snake_case on the way out, add default values for null safety, and target JSON, XML, Java or CSV.

How to use this tool

  1. Paste an example input payload (JSON) on the left.
  2. Choose the output MIME type and how output keys should be named.
  3. Tick Null-safe defaults to add default values so missing fields do not break the mapping.
  4. Copy the script into a Transform Message component, or download it as a .dwl file for src/main/resources/dwl/.
