Password & Secret Key Generator

Generate passwords, client secrets and encryption keys with your browser's cryptographically secure random number generator (crypto.getRandomValues), using rejection sampling so every character is equally likely. Includes ready-sized keys for the Mule secure properties module (16, 24 or 32 characters for AES-128/192/256), hex and Base64 secrets for API clients, and an entropy estimate for each value.

How to use this tool

  1. Choose a format: a password, a hex / Base64 / Base64URL secret, or an AES key for secure properties.
  2. Set the length and how many values to generate; for passwords pick the character sets to use.
  3. Press Generate for a fresh batch — nothing is stored or sent anywhere.
  4. Store the key in a secrets manager or as a runtime property (-Dmule.key=…) — never commit it to source control.
