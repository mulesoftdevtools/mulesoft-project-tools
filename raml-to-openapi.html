RAML to OpenAPI Converter

Convert a RAML 1.0 API specification into an OpenAPI 3.0 document. Handles titles, base URIs, nested resources, HTTP methods, URI/query/header parameters, request and response bodies and simple type declarations — and tells you clearly when it meets a RAML feature it cannot fully translate.

How to use this tool

  1. Paste your RAML 1.0 definition into the input box (it should start with #%RAML 1.0).
  2. Pick whether you want the result as YAML or JSON.
  3. Press Convert — the OpenAPI 3.0 document appears on the right, along with any conversion notes.
  4. Read the notes carefully: traits, resource types and !include files are reported rather than silently dropped.
  5. Use Copy or Download to take the result into your project.
RAML 1.0 input
OpenAPI 3.0 output 

              

            

          

          

          
Scope: this converter covers the structure used by the great majority of hand-written RAML APIs. Multi-file RAML that relies on !include cannot be resolved in the browser — flatten it into a single file first.
