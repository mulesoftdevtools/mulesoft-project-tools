JSON Diff & Compare

A text diff flags every re-ordered key and changed indent; this tool compares the data. It parses both documents and reports what was added, removed or changed, with the JSONPath of each difference — perfect for checking an API response against a baseline, reviewing a DataWeave change or spotting a field that silently changed type (for example a number that became a string).

How to use this tool

  1. Paste the original JSON on the left and the changed JSON on the right (or open/drag files onto each box).
  2. Differences appear below as you type, each with its path and the old and new values.
  3. Tick Ignore array order when arrays are sets (for example tags or IDs), and Ignore case for case-insensitive string comparison.
  4. Copy the report as tab-separated text to paste into a ticket or spreadsheet.
