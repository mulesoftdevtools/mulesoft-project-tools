Text Diff Checker

Compare two versions of a file, payload or configuration and see precisely which lines were added, removed or left alone. Options let you ignore case and whitespace so you can focus on changes that actually matter.

How to use this tool

  1. Paste the original text on the left and the changed text on the right.
  2. Press Compare — the diff appears underneath with a summary count.
  3. Lines prefixed + exist only in the new version; - lines only in the old one.
  4. Turn on Ignore whitespace or Ignore case to filter out cosmetic differences.
