JWT Decoder

Paste a JSON Web Token to see its decoded header and payload, plus a readable summary of the standard claims — issuer, subject, audience, issued-at and expiry, with a clear indication of whether the token has already expired.

How to use this tool

  1. Paste the JWT — all three dot-separated parts. A leading Bearer prefix is stripped automatically.
  2. The header and payload are decoded immediately and shown side by side.
  3. Check the claims summary for expiry status and the standard registered claims.
  4. Nothing is transmitted anywhere — the token is decoded entirely inside your browser.
