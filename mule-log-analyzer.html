Mule Log Analyzer

Paste the output of a Mule 4 runtime, Anypoint Studio console or CloudHub / Runtime Manager log and get it back as structured entries: level, timestamp, flow, event (correlation) ID and message. Multi-line entries such as the Mule error banner and stack traces stay attached to the line that started them, and you get counts by level, the busiest flows and every Error type that occurred.

How to use this tool

  1. Paste your log text — or click Open file / drag a .log file onto the box. Files are read in your browser, never uploaded.
  2. Use Minimum level to hide noise, for example only WARN and above.
  3. Type an event ID, flow name or any text into Filter to follow a single request through the log.
  4. Download the filtered entries as CSV for a spreadsheet or an incident report.
Log output
Entries
Recognised formats: the Mule 4 default pattern (LEVEL date [thread] [processor: …; event: …] logger: message), CloudHub / Runtime Manager downloads and most Log4j 2 patterns that start with a level and an ISO-style timestamp.
