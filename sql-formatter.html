SQL Formatter

Make long, single-line SQL readable before you paste it into a Mule Database connector operation. Clauses, joins and conditions each get their own line, sub-queries are indented, and keywords can be upper- or lower-cased. Mule named parameters (:customerId) and inline DataWeave (#[vars.id]) are preserved exactly, and the tool lists every parameter it finds so you can build the inputParameters map.

How to use this tool

  1. Paste one or more SQL statements.
  2. Choose the indentation and keyword case, or pick Minify to collapse the query onto one line for an XML attribute.
  3. Read the message under the editor: it lists the :named parameters and warns about positional ? parameters or inline expressions.
  4. Copy the result into the SQL Query Text of your Select, Insert, Update or Delete operation.
