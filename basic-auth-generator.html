Basic Auth Header Generator

Build the Authorization: Basic … header for a username and password, with UTF-8 handled correctly, plus copy-ready snippets for cURL, a DataWeave expression that builds the header from secure properties at runtime, and a Mule 4 http:request-config with basic authentication. Paste an existing header into the decoder to see which credentials it carries.

How to use this tool

  1. Enter the username and password — the header is generated as you type, entirely in your browser.
  2. Copy the header value, the full header line, or one of the snippets.
  3. In Mule, prefer the HTTP Request basic-authentication configuration with values from an encrypted secure properties file over hard-coding the header.
  4. To inspect a header, paste it into Decode a header below.
